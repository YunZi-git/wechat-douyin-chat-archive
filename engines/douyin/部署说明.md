# 抖音聊天记录提取 · 本地部署说明

开源项目：[TeamBreakerr/douyin-chat-export](https://github.com/TeamBreakerr/douyin-chat-export)
部署方式：**源码本地运行**（本机无 Docker，故未用 README 推荐的容器方案）

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `backend/` `extractor/` `common/` | FastAPI 后端与采集器源码 |
| `frontend/dist/` | 已构建的 Vue 3 前端（由后端直接托管） |
| `.venv/` | Python 3.11 虚拟环境（项目依赖已装好） |
| `data/` | 运行时数据：`chat.db`（聊天库）、`panel_config.json`（API token / 面板密码）、`media/`（图片语音视频）、`browser_profile/`（登录态） |
| `启动.bat` | 一键启动脚本 |

## 启动 / 停止

双击 `启动.bat`，或在终端执行：

```bash
cd 抖音聊天记录提取
.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

- 浏览界面：<http://127.0.0.1:8000>
- 控制面板：<http://127.0.0.1:8000/panel>
- 停止：窗口内按 `Ctrl+C`

## 首次使用三步

1. **登录**：打开 `/panel` → 登录 → 二选一
   - **Cookie 导入**（最简单）：浏览器登录 douyin.com → F12 → Application → Cookies → `https://www.douyin.com` → 右键 Copy all cookies → 粘贴导入
   - **本地扫码**：仓库根目录执行 `.venv\Scripts\python.exe login.py`，弹出真实浏览器扫码
2. **采集**：`/panel` → 采集，选择增量/全量并勾选会话
3. **浏览/导出**：`/` 查看聊天；`/panel` → 导出/导入，导出 ChatLab JSON/JSONL 或整库 SQLite

## 环境信息

- Python 3.11.9（`.venv`），依赖见 `requirements.txt`
- Node.js v24.21.0（仅构建前端时需要）
- Playwright Chromium 158 已安装到 `%LOCALAPPDATA%\ms-playwright`
- 数据全部保存在本目录 `data/` 内，可直接备份该目录

## 开放 API

`data/panel_config.json` 的 `api_token` 字段，请求头 `Authorization: Bearer <token>`，
只读：会话列表、消息、按日期/区间、逐日统计、聊天长图渲染等，详见 README。

## 常用环境变量

`MODE=web|scraper|all`、`HEADLESS=true`、`SCRAPER_INCREMENTAL=true`、
`SCRAPER_FILTER=会话名`、`SCRAPER_SCHEDULE="0 */6 * * *"`。
